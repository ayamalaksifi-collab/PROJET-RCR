Corpus - Semaine 2
Ce dossier contient les structures pour les medicaments numerotes de 12 a 26 dans le fichier Excel source.

Pour chaque medicament :
- Raw/ : placer le document RCP original en PDF (Rcp.pdf).
- Extracted/ : placer le texte extrait du PDF (Rcp.txt).
- Processed/ : placer les donnees structurees au format JSON (Rcp.json).
Ne pas inventer les informations : le JSON doit etre base sur le RCP.
